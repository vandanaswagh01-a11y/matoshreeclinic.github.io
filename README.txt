# Matoshree Clinic Website

A premium, responsive static website for Matoshree Clinic, Panchavati, Nashik.

## Files
- index.html — website
- style.css — design and responsive styling
- script.js — mobile menu
- logo.svg — custom clinic logo

## Before publishing
1. Replace the doctor placeholder on the hero section with a professional doctor/clinic photo if desired.
2. Confirm the clinic address and Google Maps pin.
3. Confirm professional title/specialty wording and any fee/service claims.
4. Add a real appointment form later if you want patients to submit details online.
5. Buy a domain and hosting, then upload these files.

## Easy hosting options
For a simple static site, upload the files to a static host such as GitHub Pages, Netlify, Vercel, or your regular web host. A custom .in domain can then be connected to it.
